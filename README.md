# AI Loan Risk Prediction & Lead Prioritization System

## Overview

A machine learning platform that predicts loan approval probability, customer risk level, and lead priority for financial institutions.

## Features

- Loan Risk Prediction
- Lead Prioritization
- Machine Learning Models
- FastAPI REST APIs
- PostgreSQL Storage
- Docker Containerization
- PySpark Analytics
- LLM-Based Explanations
